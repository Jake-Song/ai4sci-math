# 콜라츠 추측 연구 기록

**전체 콜라츠 추측은 이 작업에서 증명하지 못했다.** 검증한 것은 하강 명제와
원래 추측의 동치, 세 종류의 시작값에 대한 하강, 후보 가설의 반례다.
추가 검토에서는 **공통 하강 횟수 상한의 부재**와 **누적 덧셈 항을 포함한 정확한
하강 판정식**을 증명했다. 이 결과들은 전체 추측의 참·거짓을 결정하지 않는다.
아래의 `C`, `H`, `R`은 미해결 명제이며, 이를 참으로 선언하지 않는다.

기존 증명은 [Collatz.lean](../lean/Collatz.lean), 추가 분석은
[CollatzAnalysis.lean](../lean/CollatzAnalysis.lean)에 있다. 문서의 ID를 코드에서
검색하면 대응하는 명제와 증명을 볼 수 있다. 이 기록은 결과를 검토할 수 있도록
가정, 논리적 단계, 반례와 남은 의무를 정리한 것이다.

## 1. 정의와 명제 현황

표준 콜라츠 함수를 사용한다. 홀수 단계에서 2로 나누는 연산을 합치지 않는다.

$$
C(n)=\begin{cases}n/2&n\equiv0\pmod2,\\3n+1&n\equiv1\pmod2.\end{cases}
$$

`step n`은 $C(n)$, `iterate k n`은 $C^k(n)$이다.
$C^0(n)=n$이며 1에서 멈추도록 정의하지 않았으므로 $1\to4\to2\to1$도 유지한다.
Lean에서는 자연수 전체에 함수를 정의해 $C(0)=0$이지만, 추측의 대상은 **양의 정수**다.

| ID | 명제 | 상태 | Lean 선언 |
| --- | --- | --- | --- |
| C | 모든 양의 정수는 유한 번 반복하면 1에 도달한다 | 미해결 | `Conjecture` |
| H | 모든 $n>1$은 유한 번 반복하면 양의 정수 $m<n$에 도달한다 | 미해결 | `Descent` |
| L1–L2 | 한 단계 및 임의의 유한 반복은 양수를 보존한다 | 증명 완료 | `step_pos`, `iterate_pos` |
| L3 | $C^{a+b}(n)=C^b(C^a(n))$ | 증명 완료 | `iterate_add` |
| T1 | H를 가정하면 C | 조건부 정리, 검증 완료 | `conjecture_of_descent` |
| T2–T3 | C이면 H, 따라서 C와 H는 동치 | 증명 완료 | `descent_of_conjecture`, `conjecture_iff_descent` |
| D1 | 짝수 $n>1$은 1회 후 하강 | 증명 완료 | `even_descent` |
| D2 | $n>1,\ n\equiv1\pmod4$이면 3회 후 하강 | 증명 완료 | `one_mod_four_descent` |
| D3 | $n\equiv3\pmod{16}$이면 6회 후 하강 | 증명 완료 | `three_mod_sixteen_descent` |
| R | 나머지가 7, 11, 15인 모든 $n>1$의 유한 시간 하강 | 미해결 | `RemainingDescent` |
| T4–T5 | H와 R, 따라서 C와 R은 동치 | 증명 완료 | `descent_iff_remaining`, `conjecture_iff_remaining` |

| F2 | 모든 $n>1$에서 3회 이내에 시작값보다 작아진다 | 반례로 기각 | `not_every_orbit_descends_within_three` |
| M1–M5 | $2^m-1$의 초기 궤도 공식과 처음 $2m$회 비하강 | 증명 완료 | `mersenne_even_iterate`, `mersenne_odd_iterate`, `mersenne_no_descent` |
| U1–U2 | 모든 시작값에 공통인 유한 하강 횟수 상한은 없다 | 증명 완료 | `arbitrarily_long_non_descent`, `no_uniform_descent_bound` |
| A1–A3 | 실제 궤도의 단계 수와 누적항을 계산하고 등식을 보존한다 | 정의 및 증명 완료 | `orbitStats`, `orbitStats_count`, `orbit_affine_identity` |
| A4 | 누적항을 포함한 부등식이 하강의 필요충분조건이다 | 증명 완료 | `descent_iff_affine_lt` |
| F3 | 배율이 1보다 작기만 하면 시작값보다 작아진다 | 반례로 기각 | `slope_only_counterexample` |

여기서 “하강”은 **시작값보다 작아짐**을 뜻한다. 직전 항보다 작아지는 것만으로는 부족하다.
동치 정리를 증명했다고 해서 동치인 두 명제 자체를 증명한 것은 아니다.

## 2. 핵심 가설 H와 강한 귀납법

전체 목표 C는 다음과 같다.

$$
\forall n>0,\quad\exists k\ge0,\ C^k(n)=1.
$$

세운 가설 H는 다음과 같다. 반복 횟수는 시작값마다 달라도 된다.

$$
\forall n>1,\quad\exists k>0,\ 0<C^k(n)<n.
$$

### T1: H를 가정한 증명

1. $n=1$이면 0회 반복으로 이미 1에 도달한다.
2. $n>1$이라 하고, 모든 양의 정수 $m<n$에 대해 1에 도달한다고 귀납 가정한다.
3. **H를 사용하면** 어떤 $k>0$에 대해 $m=C^k(n)$이 $0<m<n$을 만족한다.
4. 귀납 가정을 이 $m$에 적용하면 어떤 $j\ge0$에 대해 $C^j(m)=1$이다.
5. L3으로 $C^{k+j}(n)=C^j(C^k(n))=C^j(m)=1$이다.

따라서 H이면 C이다. **이 증명의 미해결 전제는 3번에서 사용한 H**다.
강한 귀납법은 H를 대신 증명해 주지 않는다.

### Lean 코드의 목표 변화

`conjecture_of_descent (h : Descent) : Conjecture`의 `h`가 바로 명시적인 가정이다.

| 코드 | 적용 전 목표 또는 맥락 | 적용 후 얻는 것 |
| --- | --- | --- |
| `intro n` | 모든 양의 정수의 도달성 | 임의의 `n`에 대한 `0 < n → ReachesOne n` |
| `induction n using Nat.strong_induction_on` | 해당 `n`의 도달성 | 모든 `m < n`의 양수 조건부 도달성을 제공하는 `ih` |
| `intro hn` | `0 < n → ReachesOne n` | `hn : 0 < n`, 목표 `ReachesOne n` |
| `by_cases h1 : n = 1` | `ReachesOne n` | 시작값 1인 경우와 아닌 경우로 분리 |
| `obtain ⟨k, _hk, hm, hlt⟩ := h n (by omega)` | `n > 1`에서 도달성 | H를 사용해 `hm : 0 < iterate k n`, `hlt : iterate k n < n` 확보 |
| `obtain ⟨j, hj⟩ := ih (iterate k n) hlt hm` | 더 작은 값의 도달성을 이용할 수 있음 | `hj : iterate j (iterate k n) = 1` |
| `exact ⟨k + j, ...⟩` | 어떤 횟수에 1에 도달함을 보여야 함 | 증명할 등식은 `iterate (k+j) n = 1` |
| `rw [iterate_add]; exact hj` | 위의 합성 등식 | 목표가 `hj`와 같아져 완료 |

`omega`는 자연수의 선형 산술·상수 나눗셈·나머지 조건을 처리한다.
무한한 콜라츠 궤도의 수렴을 자동으로 증명하는 전술은 아니다.

### T2–T3: 역방향도 성립한다

C를 가정하고 $n>1$을 택한다. 1에 도달하는 횟수 $k$가 존재한다.
$k=0$이면 $n=1$이어서 모순이므로 $k>0$이다.
따라서 $0<C^k(n)=1<n$, 즉 H가 성립한다.

결국 **C ↔ H**다. H는 문제를 귀납법에 맞게 바꿔 쓴 형태이며, 더 쉬운 명제로
증명되었다거나 새로운 돌파구를 얻었다는 주장은 하지 않는다.

## 3. 실제로 증명한 하강 경우

아래 결과는 유한한 표본 검사가 아니라, 각 조건을 만족하는 **모든** 정수에 대한 증명이다.
각 화살표의 짝홀 조건과 나눗셈 등식도 Lean으로 검증했다.

### D1: 짝수

짝수 $n>1$이면 $n\ge2$이므로 $0<C(n)=n/2<n$이다.

### D2: 4로 나눈 나머지가 1

$n=4a+1>1$로 쓰면 자연수 $a\ge1$이다.

$$
4a+1\ \to\ 12a+4\ \to\ 6a+2\ \to\ 3a+1.
$$

첫 항은 홀수이고 다음 두 항은 짝수다.
마지막 값은 양수이며 $(4a+1)-(3a+1)=a>0$이므로 3회 후 하강한다.
$a=0$, 즉 $n=1$은 제외해야 한다. 이때는 3회 후 다시 1이다.

### D3: 16으로 나눈 나머지가 3

$n=16a+3$, $a\ge0$에 대해 다음과 같다.

$$
\begin{aligned}
16a+3&\to48a+10\to24a+5\to72a+16\\
&\to36a+8\to18a+4\to9a+2.
\end{aligned}
$$

연산 전 각 항의 짝홀은 홀·짝·홀·짝·짝·짝이다.
$9a+2>0$이고 $(16a+3)-(9a+2)=7a+1>0$이므로 6회 후 하강한다.
예를 들어 $3\to10\to5\to16\to8\to4\to2$다.

## 4. 기각한 후보와 남은 증명 의무

### F1: 매번 감소한다?

후보는 $\forall n>1,\ C(n)<n$이다.
$C(3)=10>3$이므로 거짓이다. 홀수 단계의 상승 때문에 이 논법은 실패한다.

### F2: 늦어도 3회면 시작값보다 작아진다?

후보는 $\forall n>1,\ \exists k\in\{1,2,3\},\ C^k(n)<n$이다.
3에서 시작한 첫 세 값은 10, 5, 16으로 모두 3보다 크다.
따라서 이 후보도 거짓이다. **F1·F2의 반례는 콜라츠 추측의 반례가 아니다.**
실제로 3은 7회 후 1에 도달한다.
U2에서는 3이라는 특정 상한을 넘어 **어떤 공통 상한도 불가능함**을 증명한다.

### R: 정확히 무엇이 남았는가?

16으로 나눈 나머지로 분류하면 D1은 모든 짝수 나머지를, D2는 1·5·9·13을,
D3는 3을 처리한다. 따라서 남은 증명 의무는 다음이다.

$$
\forall n>1,\quad
n\bmod16\in\{7,11,15\}\ \Longrightarrow
\exists k>0,\quad 0<C^k(n)<n.
$$

이것이 `RemainingDescent`(R)다. R을 가정하면 모든 시작값이 D1·D2·D3·R 중
하나에 속하므로 H를 얻는다. 반대로 H는 R을 즉시 함의한다.
따라서 **C ↔ H ↔ R**를 Lean으로 검증했다. R 자체는 증명하지 못했다.

남은 나머지류가 세 개라는 사실은 문제의 난도가 그만큼 줄었다는 뜻이 아니다.
각 나머지류는 무한하고, 이후 궤도가 같은 나머지류 안에 머무르지도 않는다.
그 궤도가 언젠가 시작값보다 작아진다는 보장이 여전히 필요하다.

후속 후보는 R의 시작값들이 D1·D2·D3에 해당하는 어떤 값에 도달한 뒤,
**원래 시작값보다도** 작아진다는 명제가 될 수 있다. 단지 처리된 나머지류에
도착하거나 바로 전 항보다 감소한다는 사실만으로는 충분하지 않다.
새 후보에는 정확한 양화 조건과 감소 기준을 적고 반례를 먼저 확인해야 한다.
유한 개의 시작값이나 고정된 반복 한도 내에서 성공해도 R의 증명으로 판정하지 않는다.

## 5. 기존 증명의 문제점과 개선 범위

코드 재검증과 수학적 검토에서 기존 정리의 잘못된 추론은 발견하지 못했다.
문제는 조건부 정리를 전체 증명으로 완성할 근거가 없다는 것이다.

| 검토 사항 | 확인한 한계 | 이번 개선 |
| --- | --- | --- |
| 강한 귀납법 | 시작값보다 작아지는 H가 없으면 귀납 가정을 적용할 수 없다 | H를 사용한 정확한 위치를 유지하고 미해결 상태를 명시 |
| 나머지류 분류 | R도 원래 추측과 동치여서 세 경우만 남았다는 사실이 해결을 보장하지 않는다 | 고정 횟수 분류 전략이 모든 시작값을 덮을 수 없음을 U2로 증명 |
| 증가·감소 배율 비교 | 홀수 단계마다 더해지는 1이 누적된다 | 누적항을 포함한 불변식 A3와 판정식 A4 증명 |

기존 정리를 제거하거나 결론을 강화하지 않았다. 아래 새 정리들은 미해결인
H·R·C를 가정하지 않는다. 초등적인 논법의 형식화이며 신규성을 주장하지 않는다.

## 6. 공통된 하강 횟수 상한이 없는 이유

### M1–M4: 초기 궤도의 정확한 공식

양의 정수 $t$에 대해 다음 두 단계는 항상 유효하다.

$$
2t-1\ \to\ 6t-2\ \to\ 3t-1.
$$

이 두 단계를 반복하면 다음 식을 얻는다. 두 번째 식에는 **$j<m$**이 필요하다.

$$
C^{2j}(2^m-1)=3^j2^{m-j}-1\quad(0\le j\le m),
$$
$$
C^{2j+1}(2^m-1)=3^{j+1}2^{m-j}-2\quad(0\le j<m).
$$

코드의 `odd_even_block`은 더 일반적인
$C^{2j}(a2^{j+r}-1)=3^ja2^r-1$, $a>0$을 $j$에 대한 귀납법으로 증명한다.
한 쌍을 진행하면 $a$가 $3a$로 바뀌고 남은 쌍이 하나 줄어든다.
`iterate_add`로 처음 두 단계와 나머지 경로를 연결한다.
여기에 $a=1, r=m-j$를 대입하면 첫 식을 얻고, 홀수 단계를 한 번 더 적용하면 둘째 식을 얻는다.

### M5: 처음 2m회 동안 시작값 아래로 내려가지 않는다

짝수 시각에는 $2^j\le3^j$이므로
$2^m=2^j2^{m-j}\le3^j2^{m-j}$이다. 양변에서 1을 빼면 원하는 비교가 된다.

홀수 시각에는 $Q=3^j2^{m-j}\ge2^m$이고 $Q\ge1$이다.
따라서 $C^{2j+1}(2^m-1)=3Q-2\ge Q-1\ge2^m-1$이다.
코드는 임의의 $k\le2m$을 $2j$ 또는 $2j+1$로 나누어 두 공식을 적용한다.

### U1–U2: 임의의 상한을 반박한다

어떤 $B\ge0$를 정하더라도 $m=B+2$, $n=2^{B+2}-1$을 택한다.
그러면 $n>1$이고 $B\le2m$이므로 M5에 의해 처음 B회 동안 하강하지 않는다.
지수의 `+2`는 $B=0$에서도 $n>1$을 보장한다.

즉, 다음을 증명했다.

$$
\forall B\ge0,\ \exists n>1,\ \forall k\le B,\quad C^k(n)\ge n.
$$

`no_uniform_descent_bound`는 공통 상한 B가 있다고 가정한 뒤, 위 n을 넣어 모순을 얻는다.
이 n에서도 B회 이내에 하강해야 한다는 주장과, 그 동안 하강하지 않는다는 M5가 충돌한다.

**여기서 시작값 n은 B마다 달라진다.** 하나의 시작값이 영원히 하강하지 않는다고
증명한 것이 아니다. 따라서 이 정리는 콜라츠 추측의 반례가 아니며,
시작값별로 서로 다른 유한 시간에 하강할 가능성과 양립한다.

유한 개의 나머지류 각각에 고정된 하강 횟수 $k_1,\ldots,k_s$를 배정해
모든 $n>1$을 덮을 수 있다면 $B=\max(k_1,\ldots,k_s)$라는 공통 상한이 생긴다.
U2는 **이 형태의 전략**을 배제한다. 시작값에 따라 횟수가 달라지는 증명이나
재귀적·귀납적인 분류까지 배제하지는 않는다.

## 7. 실제 궤도의 정확한 하강 조건

### A1–A3: 누적 덧셈 항 추적

`orbitStats k n : OrbitStats`는 n에서 k회 진행하는 동안의 `oddSteps`(o),
`evenSteps`(e), `offset`(b)를 반환한다. 현재 값은 기존 `iterate k n`을 사용한다.
세 초기값은 0이며, **실제 현재 값의 짝홀**에 따라 갱신한다.

| 다음 단계 | 갱신 |
| --- | --- |
| 짝수 단계 | $e\leftarrow e+1$, o와 b는 유지 |
| 홀수 단계 | $o\leftarrow o+1,\ b\leftarrow3b+2^e$, e는 유지 |

k에 대한 귀납법으로 다음 불변식을 증명한다.

$$
o+e=k,\qquad 2^eC^k(n)=3^on+b.
$$

- 초기 단계: $o=e=b=k=0$이므로 등식은 $n=n$이다.
- 짝수 단계: 현재 값 x가 짝수이므로 $2^{e+1}(x/2)=2^ex$다.
  Lean에서는 나누어떨어짐을 먼저 증명하여 자연수 나눗셈의 버림 문제가 없음을 확인한다.
- 홀수 단계: $2^e(3x+1)=3(2^ex)+2^e=3^{o+1}n+(3b+2^e)$다.
  `rw [ih]`는 귀납 가정의 등식을 대입하고 `ring`은 남은 대수 등식을 검증한다.

임의로 골라낸 짝홀 패턴을 실제 궤도라고 가정하지 않았다. 이 함수는 유한한
궤도 증명용이며, 큰 범위의 수치 탐색을 위한 성능 최적화는 하지 않았다.

### A4와 F3: 배율과 누적항을 함께 비교해야 한다

$2^e>0$이므로 위 불변식에서 정확히 다음을 얻는다.

$$
C^k(n)<n\quad\Longleftrightarrow\quad 3^on+b<2^en.
$$

기존 하강 예제 및 새 반례를 이 식으로 다시 볼 수 있다.

| n | k | o | e | b | $C^k(n)$ | 시작값보다 작은가? |
| --- | --- | --- | --- | --- | --- | --- |
| 5 | 3 | 1 | 2 | 1 | 4 | 예: $3\cdot5+1<4\cdot5$ |
| 3 | 6 | 2 | 4 | 5 | 2 | 예: $9\cdot3+5<16\cdot3$ |
| 3 | 8 | 3 | 5 | 47 | 4 | 아니오: $27\cdot3+47>32\cdot3$ |

마지막 행은 $3^o<2^e$만 검사하는 판정이 틀렸다는 반례다.
3의 궤도는 7회 후 1에 도달하고 8회 후 다시 4가 된다.
이는 **8회 시점의 하강 판정**에 대한 반례이며, 3이 언젠가 하강한다는 사실을 부정하지 않는다.

### 여전히 남은 증명 의무

모든 $n>1$에 대해 어떤 $k>0$에서
$3^{o(k,n)}n+b(k,n)<2^{e(k,n)}n$이 성립함을 증명해야 한다.
**A4는 주어진 k의 판정식이지, 그런 k가 존재한다는 증명이 아니다.**
이 존재 명제는 양수 보존과 A4에 의해 H와 동치이며 여전히 미해결이다.
홀수·짝수 빈도에 대한 직관이나 유한한 실험만으로 이 존재성을 결론 내리지 않는다.

## 8. 재현과 검증 결과

프로젝트에 고정된 Lean/Mathlib `v4.24.0`을 사용한다.
Lean 설치 및 의존성 준비는 [프로젝트 안내](../README.md#run)를 따른다.
저장소 루트에서 실행한다.

```sh
cd lean
lake build Collatz
lake build CollatzAnalysis
lake build
lake env lean Collatz.lean
lake env lean CollatzAnalysis.lean
```

이번 환경에서는 공식 Lean 실행 파일을 `/tmp/lean-4.24.0-linux`에 복구했다.
현재 세션에서 위 명령을 실행할 때는 먼저 다음을 사용한다. 이 임시 경로는
다른 환경이나 재부팅 후에는 존재하지 않을 수 있다.

```sh
export PATH=/tmp/lean-4.24.0-linux/bin:$PATH
```

두 Lean 파일 끝의 `#print axioms`는 주요 정리의 공리 의존성을 출력한다.
콜라츠 추측이나 H·R을 공리로 추가하지 않았다. 미완성 증명을 뜻하는
`sorryAx`도 없다. 출력에 나타나는 `propext`, `Classical.choice`, `Quot.sound`는
Lean의 표준 논리 기반이며 콜라츠에 관한 가정이 아니다.

검증 항목:

- `lake build Collatz`: 성공. 동치·조건부 정리, 세 하강 경우, 두 반례를 검증.
- `lake build CollatzAnalysis`: 성공. 새 궤도 공식·상한 부재·불변식·판정식·반례 검증.
- `lake build`: 성공(1409 jobs). 기존 피타고라스·대수 예제를 포함한 전체 검증.
- `lake env lean Collatz.lean`: 성공. 공리 검사 출력은 이번 환경의
  [검증 로그](../lean/.lake/build/logs/Collatz.verification.log)에 저장했다.
  이 로그는 Git에 포함되지 않는 로컬 빌드 산출물이며 위 명령으로 재현할 수 있다.
- `lake env lean CollatzAnalysis.lean`: 성공. 직접 실행 출력은
  [분석 검증 로그](../lean/.lake/build/logs/CollatzAnalysis.verification.log)에 저장했다.
  이 역시 로컬 빌드 산출물이며 직접 실행 명령으로 재현할 수 있다.
- E1의 등식: $C^0(1)=1$, $C^3(1)=1$, $C(2)=1$, $C^6(3)=2$,
  $C^7(3)=1$, $C^3(5)=4$, $C^5(5)=1$을 커널로 확인.
- 위 등식은 정의와 경계값 검증용이다. 이를 전체 추측의 근거로 일반화하지 않았다.
- E2는 $m=1$에서 $j=0$과 $j=m$, 상한 $B=0$, 통계의 $k=0$,
  기존 3회·6회 하강 예제의 통계를 확인한다. 일반 정리가 포함하는 경계 조건도 명시적으로 검사한다.

이 기록은 2026-10-22의 첫 연구와 후속 검토 결과다. 전체 추측의 증명 완료를 뜻하지 않는다.

## 참고 문헌과 결과의 경계

- Terence Tao, [Almost all orbits of the Collatz map attain almost bounded values](https://arxiv.org/abs/1909.03562),
  *Forum of Mathematics, Pi* 10 (2022), e12. 임의의 무한대로 발산하는 함수
  $f$에 대해, 로그 밀도의 의미에서 거의 모든 시작값의 궤도가 $f(n)$ 이하에
  도달한다는 결과다. 모든 시작값이 1에 도달한다는 증명은 아니다.
- [IAS 강연 소개](https://www.ias.edu/video/almost-all-collatz-orbits-attain-almost-bounded-values)는
  전체 수렴 문제와 위 부분 결과를 구분한다.

이 프로젝트는 Tao의 정리를 Lean으로 옮긴 것이 아니다. 위의 초등적인 하강 논법을
별도로 형식화했다. 알려진 논법의 정리이며 수학적 신규성을 주장하지 않는다.
